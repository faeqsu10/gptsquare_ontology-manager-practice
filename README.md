## 보는 순서

1. 발표자료 1~13페이지에서 설계 배경과 두 가지 AI FDE 활용 방식을 봅니다.
2. 직접 실습할 때는 14페이지부터의 순서형 부록 또는 따라하기 MD를 펼칩니다.
3. 프롬프트는 자신의 프로젝트·브랜치·Dataset을 지정한 뒤 사용합니다.

HTML은 외부 라이브러리 없이 열립니다. 파일을 내려받아 `index.html`을 브라우저에서 열어도 됩니다. MD 링크까지 함께 쓰려면 저장소 전체를 다운로드하세요.

- ← / →: 페이지 이동
- N: 발표 메모
- F: 전체 화면
- 목차: 원하는 단계로 이동
- 전체 보기: 모든 내용을 펼쳐서 읽기
- 한 화면 맞춤: 필요할 때만 축소해서 맞추기
- Ctrl + 마우스 휠: 브라우저 확대·축소

## 공개 자료의 범위

배치 ID·측정값·일부 수량·환경 경로는 설명용 예시로 바꿨습니다. 예시 값은 원본 행이나 실제 운영 결과의 증거가 아닙니다. 데이터 점검의 관찰과 학습 흐름을 설명하는 자료이며 원본 CSV, 책 본문·캡처, 계정 정보, 회사 시스템 접속 정보는 포함하지 않습니다.

참고 도서: 이현종, 『팔란티어 파운드리, 판단을 설계하라』, Chapter 10. 책의 관점을 실습에 맞춰 요약한 자료이며 공식 교재나 Palantir 공식 문서가 아닙니다.

두 AI FDE 프롬프트는 사용 경험을 바탕으로 다듬은 재구성본입니다. 실제 과거 입력문의 직접 인용이 아닙니다.

설정 메뉴는 Foundry 환경에 따라 달라질 수 있습니다. 따라하기 문서는 기존 성공 기록의 재구성이며, 모든 환경에서 전 과정을 새로 검증한 절차는 아닙니다. Action의 Test run과 실제 Submit을 구분하세요. HTML 안의 체험은 Foundry와 연결되지 않습니다.
